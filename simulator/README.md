# Симулятор Nimbus

Предпросмотр общего UI на ПК.
Нужны Git, CMake и компилятор C/C++: MSVC, GCC или Clang.
Для MSVC используйте Developer PowerShell.

Исходники симулятора основаны на
[lvgl/lv_port_pc_vscode, release/v9.5](https://github.com/lvgl/lv_port_pc_vscode/tree/release/v9.5)

## Сборка и запуск

Из корня проекта, в терминале с настроенным компилятором:

```sh
git submodule update --init --recursive
cmake -S simulator -B .cache/preview -DCMAKE_BUILD_TYPE=Release
cmake --build .cache/preview --config Release --parallel 2
cmake --build .cache/preview --config Release --target run --parallel 2
```

SDL2 скачивается автоматически, если не установлен. LVGL и FreeRTOS
используются из submodules. Сборка ограничена двумя параллельными задачами.
Для другого компилятора используйте отдельный каталог сборки.

Для FreeRTOS добавьте `-DUSE_FREERTOS=ON` к команде конфигурации.

На Windows с MinGW также доступен скрипт:

```powershell
.\scripts\preview.ps1
.\scripts\preview.ps1 -FreeRTOS
.\scripts\preview.ps1 -Jobs 1
```

Повторный запуск без конфигурации и сборки:

```powershell
.\scripts\preview.ps1 -RunOnly
.\scripts\preview.ps1 -RunOnly -FreeRTOS
```

Запускается готовый `.cache/preview/bin/nimbus-sim.exe` (с FreeRTOS —
`.cache/preview-freertos/bin/nimbus-sim.exe`). Если файла нет, сначала выполните
обычную сборку. Изменения исходников требуют новой сборки.
Параметры `-RunOnly` и `-BuildOnly` несовместимы.

## Управление

Нажмите на окно симулятора, чтобы управлять им с клавиатуры.

| Клавиши | Действие |
|---|---|
| ← / → | Предыдущая / следующая страница |
| Удержать → 1,5 с | Открыть / закрыть настройку яркости |
| Удержать ← 1,5 с | Открыть подтверждение выключения |
| ↑ / ↓ | Изменить значение текущей страницы на 1 |
| Shift + ↑ / ↓ | Изменить значение на 10 |
| PageUp / PageDown | Следующее / предыдущее состояние оформления |
| Home | Сбросить значение текущей страницы |
| `R` | Перезапустить, в том числе после выключения |
| `U` | Подключить / отключить USB |
| `E` | Включить / выключить ошибку сенсора |
| `C` | Включить / выключить калибровку IAQ |

В настройке яркости ← / → меняют яркость на 5%.
В подтверждении выключения ← выбирает «Да», → — «Нет»;
повторное нажатие подтверждает выбранный ответ.

Если экран потускнел или погас, нажмите ← или →, чтобы разбудить его.
Все показания демонстрационные. Изменённые значения сохраняются при листании
и `R`, но сбрасываются после закрытия окна. Для выхода закройте окно.
