# Симулятор Nimbus

UI прошивки на ПК: тот же код `firmware/components/ui/view` и те же картинки и шрифты из `firmware/assets`. Измерения и питание выдуманные.

Нужны CMake 3.24+ и Visual Studio 2026 с компонентом C++. SDL2 и LVGL скачиваются при первой конфигурации.

## Сборка и запуск

Из каталога `simulator`:

```sh
cmake --preset sim
cmake --build --preset sim
.\build\Release\nimbus-sim.exe
```

## Управление

| Клавиша | Действие |
|---|---|
| ← / → | Кнопки PREV / NEXT; удержание 1,5 с — долгое нажатие |
| `I` | Следующий уровень IAQ |
| `T` | Следующая температура |
| `H` | Следующая влажность |
| `C` | Калибровка IAQ вкл/выкл |
| `E` | Ошибка сенсора вкл/выкл |
| `U` | USB подключить/отключить |
| `B` | Следующий уровень батареи |

Первые 3 с измерений нет. Подсветку изображает затемнение окна. Сна, сторожевых таймеров и выключения при разряде нет; после подтверждения выключения окно гаснет.
