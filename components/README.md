# Компоненты новой реализации

Каталог предназначен только для нового кода Nimbus v2. Компоненты старой версии
удалены. Начат `board`: безопасные GPIO, ADC oneshot/eFuse calibration и
аппаратная подготовка reset/deep-sleep. Его диагностика включается отдельно;
аппаратные результаты и ограничения — в docs/verification-log.md.

Целевая структура и границы описаны в [архитектуре](../docs/architecture.md).
Каталоги создаются вместе с реализацией, без фиктивных драйверов и заглушек,
выдающих успешную работу оборудования.

| Компонент | Назначение |
| --- | --- |
| `app` | Состояние, события, навигация и политики |
| `board` | Драйверы и пины; handles и callbacks передаются только через main |
| `sensing` | BME680, BSEC и достоверность измерений |
| `power` | Синхронный опрос батареи и сон MCU, без управления дисплеем |
| `storage` | Настройки и калибровка в NVS |
| `ui` | LVGL, дисплей, подсветка и единый display-state API |

Библиотеки Bosch будут подключены заново как закреплённые локальные зависимости
на этапе реализации `sensing`; условия и конфигурация описаны в
[bsec.md](../docs/bsec.md).
