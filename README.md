# Nimbus v2

Новая реализация с нуля под LILYGO T-Display, BME680 и аккумулятор 1150 мА·ч.
Ветка: `rewrite/nimbus-v2`.

Старые исходники и submodules удалены из этой ветки. Из предыдущей версии
сохранены готовые изображения и шрифты в `assets/`. Старый проект доступен
в истории `master`.

## Текущее состояние

Есть минимальная сборочная основа ESP-IDF 5.5.3 с новой точкой входа
`main/app_main.c`. Она выводит сообщения в последовательный порт. Драйверы платы,
измерения, UI, управление питанием и упаковка SPIFFS ещё не реализованы.
Раздел `storage` зарезервирован для будущих ресурсов интерфейса.

- [Архитектура и целевая структура](docs/architecture.md).
- [Сохранённые ассеты](docs/assets.md).
- [Назначение будущих компонентов](components/README.md).

## Сборка

Из корня проекта в PowerShell:

```powershell
. .\activate.ps1
idf.py build
```

Новая сборка не использует конфигурацию, исходники или артефакты сборки v1.
`dependencies.lock` хранится в Git; `sdkconfig` и `build/` генерируются локально.

## Устройство

- LILYGO T-Display: ESP32, ST7789 135×240, две кнопки.
- BME680: I2C, SDA GPIO21, SCL GPIO22, питание 3,3 В.
- Аккумулятор 103030: 1150 мА·ч, номинально 3,7 В, штатный разъём платы.
- В этой сессии устройство доступно на COM3; порт нужно проверять после смены
  компьютера или переподключения.

Просмотр работающей прошивки:

```powershell
idf.py -p COM3 monitor
```

Выход: `Ctrl+]`. На плате пока остаётся предыдущая прошивка. Новая основа
автоматически не прошивается; после её прошивки измерения и старый UI работать
не будут до реализации соответствующих новых компонентов.
