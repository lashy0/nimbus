# Nimbus v2

Новая реализация с нуля под LILYGO T-Display, BME680 и аккумулятор 1150 мА·ч.
Ветка: `rewrite/nimbus-v2`.

Старые исходники и submodules удалены из этой ветки; старый проект доступен
в истории `master`.

Оригиналы 42 изображений JPG/PNG лежат в `artwork/`; шрифты OTF из-за лицензии
хранятся только локально. Готовые для LVGL файлы в `firmware/assets/` созданы
официальными конвертерами LVGL; параметры — в [описании ассетов](docs/assets.md).

## Текущее состояние

Есть сборочная основа ESP-IDF 5.5.3: точка входа `firmware/main/app_main.c`,
`composition.c`, компонент `board` (безопасные GPIO, кнопки на
`espressif/button`, ST7789 и подсветка), `ui` на LVGL 8.4.0, `app` и `sensing`. Экран
вертикальный, 135×240; ресурсы читаются из раздела SPIFFS `storage`.
`ui` рисует экраны по [макету](docs/ui-mockup.png): IAQ, Temp, Hum, калибровку,
яркость и вопрос о выключении; кот моргает, если для него есть картинка с
закрытыми глазами. `app` ведёт навигацию кнопками и яркость. `sensing` читает
BME680 по I2C через BSEC2 в режиме LP (раз в 3 с) и показывает IAQ, температуру
и влажность. `storage` хранит в NVS яркость и состояние калибровки BSEC, так что
после перезагрузки калибровка продолжается. `power` показывает заряд батареи
(на USB — анимацию зарядки), выключает плату в глубокий сон по «ДА» или при
разряде; PREV или NEXT будят. Затемнение экрана по бездействию (DIM/OFF) ещё
не реализовано.
Добавлен раздел `coredump` 64 КиБ и включена запись ELF/CRC32 на flash.

## Сборка

Из корня проекта в PowerShell:

```powershell
. .\activate.ps1
idf.py -C firmware build
```

Новая сборка не использует конфигурацию, исходники или артефакты сборки v1.
`firmware/dependencies.lock` хранится в Git; `firmware/sdkconfig` и `firmware/build/`
генерируются локально.
Библиотеки Bosch (BSEC2 2.6.1.0 и драйвер BME68x) подключены как git submodules
в `firmware/third_party/`; после клонирования их нужно получить:

```powershell
git submodule update --init
```

Условия использования BSEC — в [контракте подключения](docs/bsec.md#подключение-и-лицензия).

## Устройство

- LILYGO T-Display: ESP32, ST7789 135×240, две кнопки.
- BME680: I2C, SDA GPIO21, SCL GPIO22, питание 3,3 В.
- Аккумулятор 103030: 1150 мА·ч, номинально 3,7 В, штатный разъём платы.
- В этой сессии устройство доступно на COM3; порт нужно проверять после смены
  компьютера или переподключения.

Просмотр работающей прошивки:

```powershell
idf.py -C firmware -p COM3 monitor
```

Выход: `Ctrl+]`. В логе видны запуск BSEC, восстановление его состояния
и показания раз в 20 измерений.
