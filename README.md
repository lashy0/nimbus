# Nimbus

Прошивка монитора качества воздуха на LILYGO T-Display с BME680 и аккумулятором.

Ветка `rewrite/nimbus-v2` предназначена для новой реализации с нуля под текущее
оборудование. Архитектура согласована в документе
[«Архитектура Nimbus v2»](docs/architecture.md).

Документ описывает целевую структуру, обязанности компонентов, обработку событий,
измерения, отображение батареи, энергосбережение и этапы аппаратной проверки.
На момент его добавления исходники новой реализации ещё не созданы; существующая
прошивка остаётся исторической базой ветки.

## Оборудование

- LILYGO T-Display, ESP32, ST7789 135×240.
- BME680 по I2C: SDA GPIO21, SCL GPIO22.
- Аккумулятор 103030, 1150 мА·ч, номинально 3,7 В, в штатном разъёме платы.

## Сборка существующей прошивки

ESP-IDF 5.5.3; команды выполняются из корня проекта в PowerShell:

```powershell
. .\activate.ps1
idf.py build
```

Просмотр последовательного лога:

```powershell
idf.py -p COM3 monitor
```

Выход из монитора: `Ctrl+]`. `COM3` — обнаруженный в текущем окружении порт;
на другом компьютере или после переподключения его нужно проверить заново.
