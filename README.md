# Nimbus

Портативный монитор качества воздуха на ESP32. Показывает оценку качества воздуха
(IAQ с адаптацией к разным условиям), температуру и влажность.

## Структура проекта

```text
nimbus/
├── firmware/          # Проект ESP-IDF
│   ├── main/          # Инициализация и соединение компонентов
│   ├── components/    # Компоненты прошивки
│   ├── assets/        # Готовые изображения и шрифты
│   └── third_party/   # Библиотеки Bosch
├── artwork/           # Оригиналы изображений и OTF-шрифты
├── scripts/           # Скрипты разработки
└── docs/              # Документация
```

## Аппаратная часть

| Компонент | Описание |
| --- | --- |
| Плата | LILYGO T-Display на ESP32 |
| Flash | 16 МБ на используемой плате; разделы занимают первые 4 МБ |
| Экран | ST7789, 135×240 пикселей, вертикальная ориентация, регулируемая подсветка |
| Датчик | Bosch BME680: температура, влажность, давление и сопротивление газа; IAQ рассчитывает BSEC2 |
| Кнопки | Две встроенные кнопки PREV и NEXT под экраном |
| Аккумулятор | 1150 мА·ч, 3,7 В, подключён к штатному разъёму платы |

Подключения:

| Узел | GPIO |
| --- | --- |
| Экран, SPI | MOSI — 19, SCLK — 18, CS — 5, DC — 16, RST — 23 |
| Подсветка | 4 |
| BME680, I2C | SDA — 21, SCL — 22; питание 3,3 В, адрес 0x76 или 0x77 |
| PREV | 0, активный LOW |
| NEXT | 35, активный LOW, внешняя подтяжка на плате |
| Измерение батареи | 34 — ADC1, канал 6; 14 — ADC_EN |

MISO экрана не используется (`-1`): GPIO21 занят линией SDA датчика.

## Сборка и прошивка

### Подготовка

Для сборки нужен ESP-IDF v6.1. Версия IDF закреплена в манифестах компонентов.

После клонирования получите библиотеки Bosch:

```powershell
git submodule update --init
```

### Сборка

Откройте PowerShell в корне проекта и активируйте окружение ESP-IDF.

```powershell
. .\scripts\activate.ps1
idf.py -C firmware build
```

Скрипт активации выбирает установленную v6.1. Путь к `eim_idf.json` берётся из
параметра, локальной настройки `.cache/esp-idf.json` или `IDF_TOOLS_PATH`
(включая его подкаталог `tools`). Если окружение ещё не настроено, укажите файл
конфигурации EIM один раз:

```powershell
. .\scripts\activate.ps1 -IdfConfigPath 'C:\path\to\eim_idf.json'
```

После успешной активации путь сохраняется локально; последующие вызовы работают
без параметров. Локальная настройка не попадает в Git.

`scripts/format.ps1` активирует окружение самостоятельно и тоже принимает
`-IdfConfigPath`. Для проверки форматирования без изменения файлов:

```powershell
.\scripts\format.ps1 -Check
```

Готовые изображения и шрифты из `firmware/assets/` упаковываются в SPIFFS
и записываются вместе с прошивкой. Для сборки конвертеры ресурсов не нужны.

### Прошивка и мониторинг

Подключите плату по USB. Замените `<PORT>` на порт своей платы:

```powershell
idf.py -C firmware -p <PORT> flash monitor
```

Для просмотра лога без повторной прошивки:

```powershell
idf.py -C firmware -p <PORT> monitor
```

## Диагностика перезагрузок

При panic отдельно сохраняются регистры и стеки в `coredump`. Для расшифровки
нужен ELF той самой сборки; сохраняйте `firmware/build/nimbus.elf` и `nimbus.map`
перед пересборкой. С подключённой платой:

```powershell
. .\scripts\activate.ps1
idf.py -C firmware -p COM3 coredump-info
```

В ESP-IDF 6.1 core dump использует ELF и SHA-256; выбор CRC32 удалён.
Дампы от прошивки на 5.5.3 разбирайте с сохранённым ELF и окружением 5.5.3.

Brownout и пропадание питания могут оставить прежний дамп. При трёх panic,
watchdog или brownout сбросах за серию запусков устройство уходит в сон до нажатия
кнопки. После пяти минут стабильной работы счётчик серии обнуляется.
