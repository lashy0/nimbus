# Ассеты Nimbus v2

Из версии v1 сохранены только готовые ресурсы интерфейса: 5 бинарных шрифтов
и 33 изображения. Все 38 файлов остаются без изменений; собственный C/C++ код,
таблицы координат, загрузчики шрифтов и экраны из v1 не переносятся.

Источник: дерево `assets/` предыдущей реализации, `master` на `d234ecc`.

| Каталог | Файлы / назначение |
| --- | --- |
| `assets/fonts/` | `sf_b_10.fnt`, `sf_sb_15.fnt`, `sf_sb_30.fnt`, `sf_sb_50.fnt`, `sf_sb_60.fnt` |
| `assets/img/batt/` | По четыре уровня батареи с зарядкой и без неё, 8 изображений |
| `assets/img/face/` | Состояния качества воздуха, температуры и влажности, 12 изображений |
| `assets/img/status/` | Статусы good/mid/bad/warn/crit, damp/dry, minus/nothing/plus, 10 изображений |
| `assets/img/misc/` | `base.bin`, `lightning_charge.bin`, `sun.bin`, 3 изображения |

Все эти ресурсы относятся к согласованным экранам: IAQ, температура, влажность,
яркость, батарея и выключение. При разработке UI координаты и привязки создаются
заново. Наличие картинки зарядки не означает, что аппаратное состояние зарядки
уже можно достоверно определить.

Бинарные ресурсы предназначены для LVGL 8.4.0, 16-битного цвета с соответствующим
порядком байтов. Шрифты будут загружаться из `.fnt` во время запуска. Будущие пути:
`S:/spiffs/fonts/...` и `S:/spiffs/img/...`.

Пока UI не реализован, ресурсы не включаются в образ SPIFFS и не используются
минимальной точкой входа. В каталог `assets/` не добавляются документы, исходники
и артефакты сборки.
